📊 Laptop Price Analysis using Python
📌 Project Overview

This project focuses on analyzing laptop pricing data to understand how hardware specifications, brand positioning, and product features influence laptop prices. The analysis aims to derive business-ready insights that can support pricing strategy and product decision-making.

🎯 Business Objective

To identify the key factors driving laptop prices by performing exploratory data analysis, feature engineering, and visualization using Python.

📁 Dataset Description

The dataset contains technical specifications of laptops, including:

Brand and product type

RAM, storage capacity, and storage type

CPU and GPU details

Operating system and weight

Final price (in Euros)

🛠️ Tools & Technologies

Python

Pandas

NumPy

Matplotlib

Jupyter Notebook

🔍 Analysis Approach

Data quality checks and validation

Exploratory Data Analysis (EDA)

Feature engineering (price segments, SSD flag, performance indicators)

Insight-driven visualizations

Business interpretation of results

📈 Key Insights

SSD-equipped laptops consistently command higher prices across all price segments.

Laptop prices increase sharply beyond 16GB RAM configurations.

Premium brands maintain significantly higher average prices due to strong brand positioning.

Lightweight laptops are generally priced higher, reflecting consumer preference for portability.

The mid-range segment shows the highest market competition.
